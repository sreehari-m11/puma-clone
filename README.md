# Puma Website Clone

A static front-end clone of the [Puma India](https://in.puma.com) website, built as a UI practice project using HTML and CSS.

# Overview

This project replicates the desktop design of Puma's official website,  focusing on layout, typography, and visual styling. The goal was to practice CSS techniques by cloning a real-world e-commerce website.

# Features

- Desktop UI clone
- CSS transitions and hover animations
- Inter font (closest match to Puma's custom FFDINforPuma font)

# Tech Stack

- HTML5
- CSS3
